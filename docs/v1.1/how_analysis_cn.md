# 🎇 SuperCCM参数计算流程

> 适用版本: v1.1


## 0. 图像读取

将一张图像文件作为灰度图读取，用于后续分析。

在1.1版本中，对此方法进行了优化。此方法会尝试找到一个最大的，非零像素连通的区域，
进行闭运算后将其认为是干净的ROI区域。
因此，对于含有底部额外区域的图像，以及马赛克拼接图像，具有更好的适用性。

此外，为适配不同型号的CCM，还必须指定**视野像素比例**。默认情况下为400/384(μm/pixel)，
即HRT-Ⅲ/RCM所产生图像的属性值。

## 1. 神经分割

此步骤的意义是将图像二值化，归类为角膜神经的像素值为255，非角膜神经的像素值为0。

通过一个UNet模型完成此任务，此模型的完整源代码可参见Github中的
[Segmentation-models-for-CCM-images仓库](https://github.com/qlnfm/Segmentation-models-for-CCM-images)。

在1.1版本中，对此模型进行了优化，即使用含有接缝和随机掩盖的增强数据集进行训练，以适应马赛克拼接图像的分割。

值得注意的是，UNet作为一个FCN模型，可以适应任意分辨率的输入。类似其他型号的CCM图像，例如[高视T3广域角膜共聚焦显微镜](https://www.gaush.com/product.html#section7)等，
也是可以分析的。然而他们**未经过验证**。


## 2. 骨架化

将上一步二值化图像进行骨架化以提取其拓扑结构。
此外，还过滤零散片段，并进行毛刺和伪分支点的去除。

## 3. 图化

将清洗后的骨架化图像转化为多重无向图。
对于每个像素点，其8邻域内含有1个像素的点认为是端点，含有2个像素的点认为是节段点，
含有3个及以上像素点点认为是分支点。将端点和分支点作为Node，连通的节段点作为Edge构建多重无向图。

## 4. 主要神经纤维提取

我们根据Early Neuropathy Assessment Group的[教程视频](https://www.youtube.com/watch?v=QVZVOqnzUmI)以及
[ACCMetrics的主要神经纤维判断规则](https://doi.org/10.1109/tbme.2016.2573642)，
将主要神经纤维选取规则定义如下：

1. 神经的两端位于图像边缘。定义图像边缘为图像长宽均值的5%。
2. 神经两端的欧氏距离大于图像长宽均值的50%。
3. 主要神经纤维不会重叠
4. 对于重叠的多条神经纤维，通过折返角度，长度和强度综合计算分数，得分最高的神经纤维认为是主要神经纤维，其余视为分支。

## 5. 参数计算

> 我们强烈建议在报告参数的同时报告SuperCCM版本。

各参数计算方法如下：

### 1) 分辨率 Resolution (μm/pixel)

单张图像实际视野长度(μm) / 单张图像像素长度(pixel)

### 2) 图像面积（像素） Image Area (pixel)

图像中有效区域像素总个数

### 3) 图像面积（平方毫米） Image Area (pixel)

图像面积（像素）* 分辨率 / 1000 * 分辨率 / 1000

### 4) 神经长度（像素） Length of Nerves (pixel)

两个4连通像素之间距离认为是1像素，斜向连通像素之间距离认为是sqrt(2)像素。
神经长度即为所有神经像素距离之和。

### 5) 神经长度（毫米） Length of Nerves (mm)

神经长度（像素）* 分辨率 / 1000

### 6) CNFL (mm/mm2)

神经长度（毫米） / 图像面积（平方毫米）

### 7) 主要神经纤维个数 Count of Main Nerves (n)

主要神经纤维总个数

### 8) CNFD (n/mm2)

主要神经纤维个数 / 图像面积（平方毫米）

### 9) 初级分支点个数 Count of Primary Branch Points (n)

初级分支点总个数

### 10) CNBD (n/mm2)

初级分支点个数 / 图像面积（平方毫米）

### 11) 神经面积（像素） Nerve Area (pixel)

图像中神经区域像素总个数

### 12) 神经面积（平方毫米） Nerve Area (mm2)

神经面积（像素）* 分辨率 / 1000 * 分辨率 / 1000

### 13) CNFA (mm2/mm2)

神经面积（平方毫米） / 图像面积（平方毫米）

### 14) 分支点个数 Count of Branch Points (n)

分支点总个数

### 15) CTBD (n/mm2)

分支点个数 / 图像面积（平方毫米）

### 16) CNFT

弯曲度，又称TC，为所有主要神经弯曲度平均值。
弯曲度算法参照论文：
Kallinikos P, Berhanu M, O'Donnell C, Boulton AJ, Efron N, Malik RA. Corneal nerve tortuosity in diabetic patients with neuropathy. Invest Ophthalmol Vis Sci. 2004;45(2):418-422. doi:10.1167/iovs.03-0637
使用Python复现，并经过验证：与原始结果相比，误差极小。
注意，若主要神经纤维个数为0，此值为None。

### 17) CNFrD

通过盒计数法计算二值化角膜神经图像的分形维数。
